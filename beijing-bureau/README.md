# Beijing Bureau™

**Anonymous Citizen Harmony Reporting System**

> "See something. Report everything."

Satirical front-end-only hackathon app parodying dystopian surveillance and social credit culture. Mock everything — no backend, no real AI.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion
- React Router

## Run

```bash
cd beijing-bureau
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Features

- **Landing** — propaganda hero, CTAs, radar/CCTV effects
- **Report** — anonymous tip form, evidence upload, fake image pre-scan
- **Processing** — fake AI surveillance sequence
- **Results** — social credit deduction, verdict, propaganda
- **Dashboard** — heatmap, stats, CCTV feeds, recent investigations
- **Scanner** — fake webcam biometric analysis (stretch)
- **Leaderboard** — top informants (stretch)
- **Emergency mode** — "REPORT ENTIRE DISTRICT" with sirens

Patriotism tier and reports persist in `localStorage`.

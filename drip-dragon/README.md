# Drip Dragon™

> "Your fit has been reviewed by the state."

Satirical AI-powered Chinese "fashion surveillance" hackathon app. Upload an outfit photo and receive government-grade drip analysis — completely fake, maximally serious UI.

## Run

```bash
cd drip-dragon
npm install
npm run dev
```

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion

## Features (MVP)

- Landing page with cyberpunk surveillance aesthetic
- Image upload with fake facial lock-on scanner
- Cinematic fake AI analysis sequence
- Randomized drip scores, violations, aura analysis, and roasts
- Roast mode toggle
- Shareable citizen certificate
- Luxury brand / DHGate detector (fake)

No backend. No real AI. Maximum propaganda energy.
